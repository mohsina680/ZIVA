# Coding Rules

Generated code should be simple, runnable, and maintainable.

Rules:
- Prefer clean file structure.
- Add comments only where they help understanding.
- Use semantic HTML and responsive CSS.
- For Python, use functions and clear error handling.
- For frontend projects, separate HTML, CSS, and JavaScript unless the user asks otherwise.
- Do not add unrelated deployment or infrastructure files
- Use the big data knowledge for understandings, and also Docker related as well
